
== Agrupación de interfaces y funcionalidades

=== IProfileManager

* bool ValidateEmail(string email)
* bool IsUsernameAvailable(string username)
* bool SendEmail(string email)
* bool SignUp(Player player)
* bool Login(Player player)
* Player GetPlayerByUsername(string username, bool includeFriends)
* Player GetPlayerById(int playerId, bool includeFriends)
* Player GetCurrentLogin()
* bool ClearCurrentLogin()
* bool UpdatePlayer(Player updatedPlayer)
* bool DeletePlayerByUsername(string username)

=== IHostGameManager

* bool NewGame(string difficulty, int maxPlayers, string privacy)
* bool InviteFriend(string friendUsername)

=== IGameManager

* bool JoinGame()
* List<Matches> SearchMatches()
* bool ExitGame()

=== IFriendsManager

* bool SendFriendRequest(string senderUsername, string receverUsername)
* bool AcceptFriendRequest(string senderUsername, string receverUsername)
* bool CancelFriendRequest(string senderUsername, string receverUsername)
* List<FriendRequest> GetFriendRequests(string receiverUsername)
* List<Friendship> GetFriendsByID(int playerID)

=== IChatManager

* bool SendMessage(string destiny, string message)
* bool SendGroupMessage(string message)

=== IBoardManager

* List<Player> GetMatchPlayers()
* bool MovePlayer(Player playerToMove, string positionToMove)
* bool ChallengePlayer(Player challenger, Player challenged)
* bool ShoreTile(string tile)
* List<string> SinkTiles()
** Moja aleatoriamente 4 casillas en cada orilla
** Si están secas las moja si están mojadas las hunde
* bool CaptureTreasure(Player capturer, Treasure captured)
